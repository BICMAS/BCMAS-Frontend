# BICMAS / BCMS

Business Capability Management System — Next.js App Router migration from the HTML reference prototypes in `reference-html/`.

## Stack

- Next.js (App Router) + TypeScript (strict)
- Tailwind CSS v4
- shadcn/ui + Lucide React
- React Hook Form + Zod
- TanStack Table, Recharts, Sonner, date-fns, Zustand
